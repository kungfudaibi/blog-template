## 我的职责

- 在 Vue 3、UniApp 与 Vite 前端中整理餐厅、菜品、推荐、用户和菜单上传等页面及 API 调用。
- 在 Node.js、Express 与 PostgreSQL 后端中推进认证、餐厅和菜品查询、推荐、上传与管理接口。
- 公开提交记录包含后端 demo、API 修复、AdminJS 管理界面，以及一次前后端初步串联。

## 成果

- 当前 fork 同时包含可构建为 H5/微信小程序的前端，以及带 PostgreSQL 数据结构、认证、推荐和管理接口的后端。
- 仓库提供 API 测试脚本与响应快照，用来检查健康检查、注册登录、餐厅、菜品、推荐、历史和收藏等主要路径。

## 团队与当前边界

OctodayMenu 最初来自校内开源组织，项目创意、开发流程和其他协作者贡献不属于我的个人原创；这里展示的是我在公开 fork 中继续进行的前后端工作。项目仍处于开发阶段，没有公开线上演示，也不把需要外部配置的识别流程或尚未验证的接口描述成生产可用能力。
