## 我的职责

- 从需求访谈开始维护规格、实施计划和逐项验收清单。
- 实现博客、作品集、能力地图、原创像素 Agent 以及基于公开资料的问答链路。
- 为内容校验、隐私拒答、组件交互和浏览器流程建立自动化测试。

## 成果

- 形成一份可在本地运行并继续替换内容的 Next.js 模板，使用严格 TypeScript 与 MDX 管理公开资料。
- 模型凭据只留在服务端；问答默认不持久化，资料不足时拒绝猜测，也不会自动启用付费方案。
- 已覆盖类型检查、Lint、组件测试、Playwright 浏览器测试与生产构建流程。

## 当前边界

项目仍在定制分支中，没有获得生产部署授权；真实模型调用也仍需站主提供 Cloudflare 配置后再做冒烟验证。
