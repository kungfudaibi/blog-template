# 隐私说明与数据边界

本站展示站主确认公开的文章、作品、能力档案、瞬间和关于页资料。`content/profile/` 中的 `visibility: public` 内容可显示在关于页；`private` 只控制页面过滤，不是秘密存储。不要把住址、证件、私人手机号、客户秘密、内部地址或密钥提交到仓库。

当前站点使用公开笔名 `zhujiechong`。真实姓名、学校和实习单位仍未获本站公开批准。关于页公开邮箱、微信、站主确认的 Bilibili `https://space.bilibili.com/240822507?spm_id_from=333.1007.0.0` 与 GitHub `https://github.com/kungfudaibi` 主页；此外仅公开产品规格中批准的两个作品源码链接。访客点击这些外链后会进入第三方网站，可能看到该站公开的账号、个人资料和提交记录。

本站没有访客提问、聊天记录、登录、评论、广告、站点分析、支付或订阅功能，也不会把访客输入发送给 AI 模型。首页“每日一言”从随网站发布的静态作品引语中选取，页面访问时不会调用外部语句 API。应用本身没有数据库或访客画像。

Vercel 托管页面时可能按其政策处理请求元数据或平台日志；上线前应由站主确认托管平台设置。公开站主资料在仓库中维护，需要更正时修改内容并重新部署。新增访客数据收集功能前须先更新产品规格和本说明。
