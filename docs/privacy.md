# 隐私说明与数据边界

本说明描述当前首版代码的行为，不代替 Vercel 或 Cloudflare 自身的隐私条款。上线前应由站主再次确认当前公开联系方式和适用地区要求。

## 公开内容

文章、作品、能力档案以及 `visibility: public` 的个人资料会公开显示，并可作为阿竹回答的来源。不要提交住址、证件、私人手机号、客户秘密、内部链接、密钥或未授权第三方信息。Git 仓库中的 `private` 标记不是秘密存储。

当前定制分支公开别名 `zhujiechong`，以及站主主动写入 `content/profile/contact.md` 并标记 public 的联系方式。真实姓名、学校和实习单位仍未获公开批准。站主已单独批准在五个作品中提供六个精确项目 URL：`sxu-mirror` 源码、`kungfudaibi.github.io` 演示与源码、`blog-template` 源码、`fpga_smart_car_tank` 源码和 `OctodayMenu` 源码；这项授权不扩展到 GitHub 个人主页、其他仓库或其他账号信息。访客点击外链后会进入第三方页面，并可能看到该仓库自身公开的账号、提交与项目资料。

## Agent 提问如何处理

1. 浏览器把当前问题发送到本站 `/api/agent`。
2. 服务端校验内容类型、正文大小和最多 500 字的问题，拒绝明显的提示词注入与秘密提取请求。
3. 真实姓名、学校、实习单位等受保护身份问题在检索资料前直接拒答，不调用模型。
4. 服务端只检索已发布文章、作品、能力档案和公开个人资料，最多选取有限来源上下文。
5. 其他未知个人问题在本站直接返回“资料不足”，不会调用模型。
6. 其余允许的问题会连同有限公开上下文发送给 Cloudflare Workers AI；返回内容经长度和结构校验后再交给浏览器。

因此，访客不应在问题中填写密码、Token、私人联系方式、健康/财务资料或其他敏感信息。Cloudflare 对 Workers AI 数据使用的当前说明见[官方数据使用页面](https://developers.cloudflare.com/workers-ai/platform/data-usage/)。

## 保存与日志

- 应用没有数据库，不把完整问题、回答或聊天记录写入文件、Cookie、Local Storage 或分析服务。
- Agent 响应设置 `Cache-Control: no-store`。
- 为实现每实例每分钟 5 次的基础限流，服务端会在实例内存中临时使用请求 IP/转发标识和时间戳；它不写入项目数据库，实例回收后消失。
- 应用代码不记录完整对话；Vercel、Cloudflare 和网络基础设施仍可能按各自政策处理请求元数据或平台日志，部署者应核对并配置这些平台。

## 第三方与跨服务传输

- Vercel：托管 Next.js 页面和服务端 API。
- Cloudflare Workers AI：仅在需要模型回答时处理问题和有限公开上下文。
- GitHub / GitHub Pages：仅在访客主动点击已批准的作品演示或源码链接后打开；本站不会代访客请求或嵌入这些页面。

当前没有广告、站点分析、登录、评论、订阅、支付或其他聊天第三方。任何新增 Cookie、分析、数据库、长期记忆或额外模型供应商都必须先更新规格、隐私说明并取得批准。

## 访问、更正与删除

当前应用不建立访客账户，也不保存可供查询或删除的聊天历史。公开站主资料由仓库内容文件维护；需要更正时修改对应文件并重新部署。当前没有公开联系渠道；未来若增加，必须先完成隐私审计并更新 `content/profile/contact.md`。
